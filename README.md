One line roasting the fridge humming at 2 AM. Entry for the make.fun Midnight Fridge Roast bounty.

## The entry

> It's 2 AM and the fridge is humming its one song again, like a backup singer who never learned the words but still demands a solo - and the leftovers aren't even listening.

## Run

```sh
python3 main.py
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output` by default): valid UTF-8, no trailing newline.
